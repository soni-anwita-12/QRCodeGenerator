# QRCodeGenerator
**QR Code Generator – Python**

Developed a simple and interactive QR Code Generator using Python that converts user-provided text or URLs into scannable QR codes. The project uses the `qrcode` and `Pillow` libraries to generate and save QR codes as PNG image files.

**Key Features:**
- Generates QR codes from text and URLs.
- Allows users to choose a custom filename for the generated QR code.
- Saves QR codes as PNG images.
- Includes input validation to prevent generating QR codes from empty text.
- Provides a menu-driven interface with options to generate QR codes or exit the program.

**Technologies Used:** Python, qrcode, Pillow (PIL).

**Learning Outcomes:** Gained practical experience with Python functions, conditional statements, user input handling, external libraries, image processing, and file handling.
